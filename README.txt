圣遗物全模式掉落 / Relic Any Mode
作者：AAA狙神夏乌拉（Bilibili）

【功能简介】
让 Boss 遗物（大师模式 Relic 雕像）在任意难度、任意击杀次数下都掉落，并保持原本的彩色大师稀有度。
- 专家/经典/旅途世界也能获得遗物
- 灾厄“复仇模式或大师模式”的限制被解除（专家+非复仇也会掉）
- 活动 Boss（南瓜月/霜月小 Boss）不受波次掉落限制，每次击杀必掉
- 兼容法狗魂石永恒模式（自动去重，不会双掉）
- 每件遗物都有专属的「被击败语录」，显示在物品说明里

【安装方法】
一、创意工坊安装（推荐）
1. 打开 Steam → 创意工坊（tModLoader）→ 搜索 “圣遗物全模式掉落”/“Relic Any Mode”
2. 点击「订阅」
3. 启动 tModLoader，在「模组」列表里确认该模组已启用
4. 进入任意世界即可生效（不需要新开世界）

二、手动安装（下载 .tmod 文件）
1. 下载 RelicAnyMode.tmod
2. 将它放入：
   C:\Users\<你的用户名>\Documents\My Games\Terraria\tModLoader\Mods\
3. 启动 tModLoader → 模组 → 找到「圣遗物全模式掉落」→ 启用
4. 重启游戏/重新进入世界

【联机说明】
- 单人游戏：直接生效。
- 多人联机：掉落由服务器结算，服务器端必须安装并启用本模组；客户端也装的话物品说明里的语录能正常显示。

【配置】
主菜单 → 模组 → 圣遗物全模式掉落 → 配置：
- 强制掉落 Boss 遗物（默认开）
- 显示被击败语录（默认开）
- 详细日志（默认开）

【版本要求】
tModLoader 1.4.4.9（2026.8.3.0）。作者本机测试环境为灾厄 2.2.4 + 法狗全家桶 + 24 个模组。

【兼容性说明】
- 支持原版 Boss、灾厄本体、灾厄附属（催化剂/灾厄熵/灾厄大修/CJMOD 等）、法狗魂石。
- 多段 Boss（双子、毁灭者、Astrum Deus、Anahita/Leviathan、Exo Mechs 等）保持原版“一场战斗只掉 1 件”的规则。
- 少数 Boss 在当前版本中没有遗物物品（如 THE LORDE、Primordial Wyrm、原版 Torch God 等），无法掉落“自己的遗物”。
